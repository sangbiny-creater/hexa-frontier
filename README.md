# HEXA FRONTIER v2 — P0 프로토타입

> 헥사 지도를 넓혀 가며 스피릿을 모으고 키우다 보스에 막히면, **지금 더 놀거나 / 1~2시간 훈련·채집을 맡기거나 / 쉬게 해서** 돌파하는 자동전투 RPG.

P0의 목적은 기획서 11장 그대로 **"막힘 → 성장 → 돌파"의 재미 검증**입니다. 그래픽은 임시 도형입니다(D4).

## 실행

```bash
npm install
npm run dev        # http://localhost:5181
```

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 (Vite) |
| `npm test` | 코어 로직·튜토리얼·RPG 테스트 62개 (Vitest) |
| `npm run typecheck` | 타입 검사 |
| `npm run build` | 타입 검사 + 배포용 빌드 |
| `npx tsx sim/rpg-bot.ts` | RPG 밸런스 봇: 스테이지 1~10판을 차례로 깰 때 판별 턴·레벨·사망 |
| `npm run sim:tutorial` | 봇이 아렌의 안내만 따라 P00 튜토리얼을 끝까지 진행 (패배 칸·골드 벌기 횟수·시간) |
| `npx tsx sim/p00-minlv.ts <전투> <편성> <적레벨…>` | 튜토리얼 칸 조정용: 적 레벨별 '이기는 최소 레벨' |
| `npm run sim:tune` | 파티 레벨·승급별 보스/일반 전투 승률표 |
| `npm run sim:boss` | 봇이 전투력만 보고 플레이할 때 보스까지 걸리는 전투 수·시간 |
| `npm run sim:power` | 권장 전투력 표(`src/data/recommended.ts`) 재생성 — 밸런스 수정 후 실행 |

## 플레이 방법 (스마트폰 세로)

**지금 버전 (D109~): 헥사 전술 전투.** 스피릿 부대를 이끌고 6×12 헥사 전장에서 턴제로 싸운다. 아군 차례에 유닛마다 이동 → 공격·기술·아이템·대기, 적군 차례에 적이 움직인다. 역할 7종(탱커·물리/마법 근접·물리/마법 원거리·힐러·서포터), 5속성 상성(×1.3/×0.75), 물리/마법·방어/마법방어, 반격, 지형, SP 기술, 장비 3칸. 10판을 깨면서 스피릿이 합류한다. 코드: `src/tactics`(규칙·인공지능·스테이지), `src/tacticsui`(화면), 밸런스 봇 `npx tsx sim/tactics-bot.ts`.

(아래는 이전 버전 기록)

스테이지식 헥사 사냥 RPG(D72~D84). 스테이지 선택 화면에서 판을 고르고, **오른쪽 아래 이동 버튼을 누르고 있거나 헥사를 톡 누르면** 걸어가고(한 칸 = 한 턴), 가는 길에 몬스터를 만나면 **자동으로 싸운 뒤** 계속 간다. 몬스터를 누르면 다가가서 싸운다. 목표가 없으면 시간이 멈춘다. 왼쪽 기술 버튼·💊물약. 빈 곳을 **끌면** 앞을 미리 볼 수 있다. **세로 화면**(D104): 맨 위 스테이지 줄, 왼쪽 위 캐릭터 창(체력·SP·경험치), 오른쪽 위 ☰메뉴, 왼쪽 아래 자동·물약·기술 칸 4개, 오른쪽 아래 이동 버튼. 기술은 쿨타임 + **SP**(D105), 테크트리는 패시브/액티브, 스피릿은 **스피릿 코어(SC)**를 먹고 레벨업. 포위되면 방어가 약해지고(D106), 보스를 잡으면 몬스터가 계속 몰려와 경험치를 벌 수 있다(D107). 스피릿은 칸을 차지하고 함께 싸우며, 포인트로 키울 속성을 고른다. 🌳기술 테크트리(디아블로식: 노드마다 여러 번, 3포인트 넣으면 아래 열림), 🛡장비, 🏪상점. 맨 위 👑보스를 쓰러뜨리고 🚪출구로 가면 클리어 → 다음 판. 한 곳에서 머뭇거리면 몬스터가 몰려온다(경험치 벌기에도 쓸 수 있음). 🏕야영지는 한 번 쉬면 15턴 뒤에 다시.

## 폴더 구조

```
src/core/   순수 게임 로직 (DOM 의존 없음, 테스트·시뮬레이터 공용)
  battle.ts     결정론적 자동전투 시뮬레이터
  analysis.ts   패배 원인 분석 (반사실 재시뮬레이션)
  game.ts       게임 상태·탐험·보상·활동·방치 보상·목표 안내
  growth.ts     레벨/승급/E+F 성장 보호
  condition.ts  컨디션 B안
  board.ts      편성판(육각 9칸)·속성 상성/상생
  clock.ts      시간 추상화 (DevClock/ManualClock) — 상용 단계에서 서버 시간으로 교체
  save.ts       버전 관리 저장
src/data/   밸런스 수치·스피릿·적·맵 (코드 수정 없이 조정)
src/ui/     React 화면
sim/        밸런스 시뮬레이션 스크립트
tests/      코어 테스트
docs/       기획서 원본, 결정 로그, P0 개발 보고서
```
