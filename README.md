# HEXA FRONTIER v2 — P0 프로토타입

> 헥사 지도를 넓혀 가며 스피릿을 모으고 키우다 보스에 막히면, **지금 더 놀거나 / 1~2시간 훈련·채집을 맡기거나 / 쉬게 해서** 돌파하는 자동전투 RPG.

P0의 목적은 기획서 11장 그대로 **"막힘 → 성장 → 돌파"의 재미 검증**입니다. 그래픽은 임시 도형입니다(D4).

## 실행

```bash
npm install
npm run dev        # http://localhost:5181
```

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 (Vite) |
| `npm test` | 코어 로직·튜토리얼 테스트 35개 (Vitest) |
| `npm run typecheck` | 타입 검사 |
| `npm run build` | 타입 검사 + 배포용 빌드 |
| `npm run sim:onboarding` | 첫 보스(고목 수호자) 온보딩 결과를 시드 10개로 확인 |
| `npm run sim:tune` | 파티 레벨·승급별 보스/일반 전투 승률표 |
| `npm run sim:boss` | 봇이 직접 플레이만으로 지역 보스까지 가는 데 걸리는 전투 수 |

## 플레이 방법 (첫 10분)

처음 켜면 **시작 화면**이 "이 게임에서 당신이 하는 일" 3가지를 보여 주고, **길잡이 헥시**가 지도 위 안내창에서 매 단계 무엇을 누를지 알려 줍니다(누를 곳은 노란 ▼ 화살표와 빛나는 테두리로 표시). 상단 **?** 버튼으로 게임 방법을 다시 볼 수 있고, **목표** 줄을 누르면 목표 칸이 선택됩니다.

1. 상단 **목표** 줄이 늘 다음 할 일을 알려 줍니다.
2. 지도에서 **빛나는 칸**을 누르고 → 왼쪽 아래 카드의 버튼(전투 시작/탐험)을 누릅니다. 스피릿이 알아서 싸웁니다.
3. 불씨 바위에서 **이그니**가 합류 → 고목 수호자에게 도전 → **아깝게 패배(HP 15% 남음)**.
4. 패배 화면이 원인(생존 부족·회복 부족)과 해결 경로(지금 파밍·동료 찾기 등)를 보여 줍니다.
5. 멧돼지 굴 너머에서 회복 스피릿 **실피** 합류 → 재도전 → **돌파** → 훈련장·채집 해금.
6. 이후 지역 보스 **바위 거인 몽돌**이 긴 벽입니다. 파밍·승급·훈련·채집·휴식을 섞어 돌파하세요.

### 개발자 도구 (상단 ⚙)
- `+15분 / +1시간 / +2시간 / +8시간 / +12시간`: 게임 시간을 즉시 앞당김 (훈련·채집·회복·방치 보상 테스트)
- `×1 / ×60 / ×600`: 게임 시간 배속
- `새 게임`: 저장 데이터 초기화

## 폴더 구조

```
src/core/   순수 게임 로직 (DOM 의존 없음, 테스트·시뮬레이터 공용)
  battle.ts     결정론적 자동전투 시뮬레이터
  analysis.ts   패배 원인 분석 (반사실 재시뮬레이션)
  game.ts       게임 상태·탐험·보상·활동·방치 보상·목표 안내
  growth.ts     레벨/승급/E+F 성장 보호
  condition.ts  컨디션 B안
  board.ts      편성판(육각 9칸)·속성 상성/상생
  clock.ts      시간 추상화 (DevClock/ManualClock) — 상용 단계에서 서버 시간으로 교체
  save.ts       버전 관리 저장
src/data/   밸런스 수치·스피릿·적·맵 (코드 수정 없이 조정)
src/ui/     React 화면
sim/        밸런스 시뮬레이션 스크립트
tests/      코어 테스트
docs/       기획서 원본, 결정 로그, P0 개발 보고서
```
