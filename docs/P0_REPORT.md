## 0-A. 2026-11-13 모바일 세로 전면 개편 (D37~D41)

사용자 피드백: "모바일 UI가 아니다, 그림을 입혀라, 아직 뭐하는 게임인지 모르겠다, 튜토리얼은 한 줄 길로, 모든 행동이 어디서 뭘 하고 무슨 효과인지 모르겠다."

- **세로 헥사 맵(아래→위)**, 칸마다 실제 몬스터·보물·동료 그림을 세우고 주인공이 칸을 따라 이동.
- **튜토리얼 한 줄 길** → 첫 보스 아깝게 패배(HP 15%) → 이때 **강화 탭이 열림** → 레벨업(622→791) → 재도전 승리 → 갈래 길·자동 사냥 개방. 테스트로 "튜토리얼 중 갈 수 있는 칸은 항상 하나"를 보장.
- **행동마다 효과 표시:** 칸 시트에 내 전투력 vs 권장 전투력 막대와 보상, 레벨업 버튼에 `🪙비용 → ⚔️+증가량`, 진화까지 남은 레벨 막대, 패배 화면에 부족한 전투력과 바로 실행 버튼.
- **진화 연출:** Lv.10/25에 그림·이름이 바뀌는 팝업(예: 쉘타이드 → 리프나이트).
- 모바일 세로 전용 레이아웃(상단 HUD, 하단 탭, 바텀 시트, 전체 화면 전투), 홈 화면 추가용 매니페스트·아이콘.
- 브라우저 375×812(모바일)에서 시작 화면 → 튜토리얼 전 구간 → 갈래 길 → 진화까지 직접 확인.

## 0. 2026-11-13 개편 — "뭐하는 게임인지 모르겠다" 대응 (D32~D36)

사용자가 튜토리얼을 넣은 뒤에도 다음을 짚었습니다: 처음에 뭘 눌러야 할지 모름, 엉뚱한 칸에서 첫 싸움부터 짐, "지금 파밍"·"휴식"·"동료 찾기"·"채집 목적지"가 무슨 뜻인지 모름, 막히면 해결책이 뭔지 모름. 그리고 **"MD에 어긋나도 되니 묻지 말고 고쳐라"**, 첫 5분에 원하는 재미는 **"숫자가 쭉쭉 오르는 성장감"**.

**바꾼 것**
1. **하나의 숫자로 안내:** 팀 ⚔️전투력을 상단에 항상 표시하고, 모든 전투 칸에 권장 전투력과 난이도 색을 붙였습니다. 권장값은 `npm run sim:power`가 실제 전투 시뮬레이션으로 측정합니다(전투력이 권장의 115% 이상이면 테스트에서 80% 이상 승리 확인).
2. **골드 레벨업:** 전투는 골드를 주고, 레벨업은 골드로 버튼을 눌러 합니다(누를 때마다 전투력 +N 표시). 경험치 개념은 뺐습니다.
3. **개념 덜어내기:** 컨디션·경상·휴식·훈련·채집·활동 탭을 끔. 자원 칸은 보물 상자, 방치 보상은 '자동 사냥'.
4. **패배 화면:** "내 546 vs 권장 630, 84 부족" + 바로 실행되는 버튼(동료 찾으러 가기 → 그 칸으로 출발 / 레벨업 / 골드 벌러 가기 → 쉬운 칸에서 바로 전투).
5. **튜토리얼:** 안내 중엔 ▼ 칸만 누를 수 있고, 첫 보스 전에 '모두 레벨업'을 직접 눌러 전투력이 오르는 걸 보게 합니다.

**측정 (봇, `npm run sim:boss` / `sim:onboarding`)**
- 튜토리얼 경로: 골드 143 → 레벨업 → 전투력 546 / 권장 630 → 고목 수호자 **HP 20~24% 남기고 아깝게 패배** → 실피 합류(전투력 756) → 돌파
- 직접 플레이만: 고목 수호자 8전(약 2분), 바위 거인 몽돌 **약 58~63전(약 18분)**

**브라우저 확인:** 새 게임 → 시작 화면 → 슬라임 무리 → 불씨 바위 → 수호자의 앞뜰 → 모두 레벨업(444→546) → 고목 수호자 패배 화면 → 멧돼지 굴 → 실피 합류 → 돌파 → 튜토리얼 종료까지 직접 진행.

이 아래 1~5장은 개편 전 기록입니다. 컨디션·훈련·채집 관련 설명은 현재 꺼져 있습니다(`BALANCE.condition.enabled = false`).

## 2. 시스템 설명

### 2.1 자동 전투 (`core/battle.ts`)
- **편성판:** 진영마다 육각 9칸(전열 3/중열 3/후열 3). 중열은 반 칸 내려가 있어 육각 인접 관계가 생깁니다.
- **진행:** 0.1초 틱마다 각 유닛의 행동 게이지가 `속도`만큼 차고, 100이 되면 행동합니다. 순서대로 도는 턴제도, 뭉쳐 싸우는 난전도 아닙니다(D6).
- **스킬 우선순위:** 필살기(에너지 100 + 조건 충족) > 액티브(쿨다운 + 조건 충족) > 기본 공격. 에너지는 평타 +12, 액티브 +20, 피격 +4.
- **스킬 조건 예:** 실피의 회복은 HP 75% 미만 아군이 있을 때만, 필살기 '숲의 축복'은 70% 미만일 때만 사용(아껴 둠). 타이드쉘의 '파도의 방벽'도 아군이 다치기 전엔 아낌.
- **타깃팅:** 기본 공격과 근접 공격은 가장 앞 열만 노림 → **전열이 살아 있는 동안 후열은 안전**. 원거리 스킬(예: 이그니 화염탄)은 HP가 가장 낮은 적을 직접 노림. 도발 중인 유닛이 있으면 단일 공격은 그쪽으로.
- **피해:** `공격 × 계수 × 60/(60+방어) × 속성배율 × (0.95~1.05)`, 전열 피격 -10%, 후열 원거리 +10%.
- **열·역할 보너스:** 전열 탱커 방어 +10%, 후열 원거리/회복 +10%, 중열 지원 +10%. 육각 인접 칸에 상생 속성 아군이 있으면 공격 +8%.
- **시드:** 같은 시드 + 같은 편성 = 완전히 같은 결과(테스트로 보장). 90초 안에 못 이기면 패배(시간 초과).

### 2.2 속성 (D14, D15)
- 상극: 물 > 불 > 숲 > 대지 > 전기 > 물 — 유리 ×1.3 / 불리 ×0.75
- 상생(인접 아군 공격 +8%): 물→숲, 불→대지, 숲→전기, 대지→물, 전기→불
- 지역 1(숲)의 적은 숲·대지 위주라 불 딜러 이그니가 강하고, 물안개 도롱뇽(물)은 이그니의 천적입니다.

### 2.3 패배 원인 분석 (`core/analysis.ts`)
같은 시드로 조건만 바꾼 **모의 전투 4회**(공격 +15%, HP·방어 +15%, 컨디션 최상, 레벨 +2)를 돌려 원인을 추정합니다.
- 원인 태그: 공격 부족 / 생존 부족 / 피로 / 상성 불리 / 회복 부족 / 시간 초과
- 사실: 보스 남은 HP, 가장 먼저 쓰러진 스피릿과 시각, "레벨 +2이면 이겼습니다" 같은 모의 결과
- 행동 버튼: 지금 승급 / 지금 파밍 / 1시간 훈련 / 2시간 채집 / 휴식 / 편성 변경 / 동료 찾기 (가능한 것만 표시)
- 보스 HP 20% 이하로 지면 "아깝다!" 표시

### 2.4 성장 (`core/growth.ts`)
- 레벨: 경험치 쌓이면 자동 상승. 필요 경험치 `12 × L^1.45`, Lv11~20 ×1.6, Lv21~30 ×2.6 (Lv30 상한).
- 승급: ★1~5, 능력치 +12%씩. 비용 성장석 5/12/25/45/70 + 골드, 최소 레벨 4/8/12/18/24.
- **E (따라잡기):** 계정 최고 레벨의 80% 미만이고 차이가 3 이상이면 경험치 ×3.
- **F (선배 전수):** Lv20 이상 스피릿이 있으면 훈련 경험치 +30%. 최종 배율 상한 **×3.5**.
- 패배해도 경험치 30%는 받습니다.

### 2.5 컨디션·경상 (`core/condition.ts`)
- 승리: 전투불능된 스피릿만 -10. 패배: -5(보스 -8), HP 30% 이하 -3, 전투불능 -10, 전투당 상한 -15.
- 효율: 80+ 100% / 60+ 97% / 40+ 93% / 20+ 87% / 0+ 80%. 컨디션 0이어도 출전 가능.
- 회복: 대기 중 +5/h, 휴식처 +15/h, **훈련·채집 중에는 회복 중단**(D23).
- 경상: 전투불능 시 25% 확률, 공격 -5%. 자연 6시간 / 휴식 2시간 / 치료소 120골드 즉시.

### 2.6 활동·방치 (`core/game.ts`)
- 훈련 1시간: 경험치 `60 + 30×레벨` (E+F 적용). 채집 2시간: 발견한 자원 헥사에 따라 성장석 10 또는 골드 300.
- 중단 시 경과 시간 비례 보상, 완료 보상은 수령 전까지 보존, **수령은 한 번만**(테스트로 보장).
- 방치 보상: 시간당 골드 40, 성장석 0.5, 최대 12시간치.
- 시간: 모든 계산은 `now`를 인자로 받습니다. 기기 시계가 과거로 가면 회복·보상을 주지 않고 경고합니다(D3). **상용 단계에서는 `Clock`을 서버 시간으로 교체해야 합니다.**

## 4. 발견한 문제 / 결정이 필요한 것

1. ~~피로 하향 나선~~ → **해결(D29).** 봇이 지역 보스에 8~11번 도전하면 컨디션 0 + 경상이 되어 Lv21~23까지 키워야 했습니다. 수치는 그대로 두고, 보스 도전 전 피로 경고와 패배 화면의 '휴식' 우선 추천을 넣었습니다. 경고를 따르면 Lv16에 돌파합니다(3.3).
2. ~~첫 보스 패배에서 경상~~ → **해결(D30).** 일반 보스에서는 경상이 생기지 않습니다(테스트로 보장).
3. **지역 보스까지 직접 플레이 40~50분**은 기획서 10장의 "지역 최종 보스 1~2일(집중형)"보다 훨씬 짧습니다. P0는 지역 하나뿐이라 의도적으로 짧게 두었으며, P1에서 1개월 볼륨(D24)에 맞게 곡선을 다시 잡아야 합니다.
4. **전투 결과의 운 요소가 매우 작음.** 같은 능력치면 시드가 달라도 결과가 거의 같습니다(승률이 0%→100%로 급변). "성장하면 확실히 깬다"는 장점이 있지만 "아슬아슬한 승부"는 드뭅니다. 치명타 같은 변동 요소를 넣을지 결정이 필요합니다.
5. **스피릿 속성 변경.** 처음엔 탱커를 대지로 잡았으나 숲 지역의 첫 전투에서 상성 불리(숲>대지)로 혼자 졌습니다. 탱커=물, 회복=숲으로 바꿨습니다.
6. 기존 폴더(`hexafrontier/.claude/launch.json`)가 미리보기 서버 설정을 가로채서, 새 프로젝트 개발 서버는 직접 실행했습니다. 다음 세션부터는 이 폴더(`hexa-frontier-v2`)에서 시작하면 `.claude/launch.json`(`hexa-v2`)이 바로 쓰입니다.
